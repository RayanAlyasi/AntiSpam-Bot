# F-107 · OpenAI-compatible adapter (hosted and local servers)

## 2026-10-17

Built in the WP-J bundle (log: `harness/progress/F-106.md`, contract `.agent/contracts/F-106.md`): `internal/ai/openaicompat` posts to `{base_url}/chat/completions` with strict `json_schema` or `json_object`, an optional key for local servers (Ollama, llama.cpp, vLLM, LM Studio), and an `auto` mode that falls back to JSON mode once after a 400/422 and stays there. `gateway.New` builds it from `ai.provider: openai_compatible`. Tests run against local `httptest` fakes only.
