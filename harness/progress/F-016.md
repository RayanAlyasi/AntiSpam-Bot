## 2026-10-17 · F-016 · route events (WP-F, PR 1)

- Built: `inbox.Router` classifies each message: protected-group members → moderate (and commands); admins (by Sender or SenderAlt) and allow-listed members → commands only; tracked but unprotected groups → commands only; untracked groups, the bot's own messages and channels → ignore; `status@broadcast` → reputation only; DMs and broadcast-list messages → DM handler. Lookup errors are returned, never guessed. `identity.Tracker.GroupState`, `identity.Participants.IsGroupAdmin` and `identity.Service.IsAllowListed` implement its interfaces.
- Deferred: the inbox worker that calls it (F-015, follow-up PR).
