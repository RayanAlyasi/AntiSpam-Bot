# F-056 deviations (content policy)

- §9.2/§9.3: a message with several content types uses one matrix row, the most specific spam vector first: view-once, status, group invites, channel shares, contacts, then the media kind (documents, videos incl. video notes, images, stickers, audio incl. voice, polls, locations/events), then links (a text with a URL), then text. An image with a link caption is an `images` message for the matrix; its link is still checked by `content.links`.
- `block_for_new` uses the just-joined window (`new_members.just_joined.window`, 24 h); `block_for_untrusted` blocks anyone not established (allow-listed and vouched members count as established).
- "double extensions" means an executable extension (apk, exe, scr, bat, cmd, js, vbs, msi, jar, ps1, …) behind an innocent one (pdf, doc, jpg, mp4, zip, …), e.g. `invoice.pdf.exe`; names are cleaned of format/control characters (right-to-left override), trailing dots and spaces first. A document whose declared mimetype is an executable type with a blocked extension is blocked too (an APK renamed `invoice.pdf`).
- Content policy and the just-joined signal are not detect analyzers: `detect.Analyzer.Analyze` sees neither the group settings nor the sender's standing. The pipeline calls `policy.Engine.Route`, which evaluates the content rules itself, and appends `policy.JustJoinedScoringSignal` to the analyzers' signals before scoring.
