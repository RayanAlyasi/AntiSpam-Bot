## 2026-10-17 · F-014 · inbox insert with dedupe and synchronous ack (WP-F, PR 2)

- Built: `app.inbox` (migration 00011) with raw proto, MessageInfo JSON and a unique key on chat, message ID, edit attribute and kind. `inbox.Writer` is the connector's message sink: a redelivery inserts nothing and returns nil, so it is acked; a failed insert returns an error, so the message stays unacked. The connector's handler returns whatsmeow's success status from it with `SynchronousAck` and the decrypted-event buffer on, so an unacked message is really redelivered.
- Tests: `TestWriterDedupes` (integration), `TestOnEventAckFollowsTheInboxInsert`.
