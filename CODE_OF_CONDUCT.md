# Code of Conduct

This project is maintained by volunteers for people who run WhatsApp communities. We want
everyone who takes part (in issues, pull requests, discussions and any other project space)
to be treated with respect, whatever their background, experience, language or beliefs.

## Expected behaviour

- Be kind and patient, especially with newcomers and with people writing in a second language.
- Disagree about ideas, not people. Assume good intent and ask before you conclude.
- Give and accept constructive feedback gracefully.
- Respect privacy. Never post someone's phone number, messages or other personal data, and
  redact spam examples before sharing them.

## Unacceptable behaviour

- Harassment, insults, threats or personal attacks.
- Discriminatory jokes or language, or sexualised content.
- Publishing others' private information without their explicit permission.
- Using the project to spam, or to target or surveil people.
- Sustained disruption of discussions.

## Reporting and enforcement

Report problems privately to the maintainers, through the contact on the repository owner's
GitHub profile. Reports are handled confidentially. Maintainers may edit or remove
contributions, and warn, suspend or ban participants who break this code, in proportion to
what happened.

This code applies in all project spaces, and when someone represents the project in public.
It is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
