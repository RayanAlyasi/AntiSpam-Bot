# Plan changes

Changes to `harness/features.json` beyond `passes` and `evidence` (adding, removing, reordering or rescoping features) need a record here, written by a human: one file per change, `<date>-<slug>.md`, saying what changed and why. The tamper audit accepts plan edits only on a branch that adds such a record. Agents can't write here, so the plan can't be quietly changed to make a feature look done.
