## 2026-10-17 · F-032 · Unknown message types via protoreflect plus coverage test

Part of the F-024 bundle (one PR; see F-024.md and `harness/deviations/F-024.md`).

- Built: Every `waE2E.Message` field is classified as handled, generic (reflected), ignored or wrapper; anything else is unknown: its strings are reflected into `unknown` text and URL surfaces, its ContextInfo is still read, and its name is returned in `BuildResult.Unknown` for the metric. `TestEveryMessageFieldClassified` fails when a whatsmeow bump adds a field.
- Deferred: The Prometheus counter itself (no metrics dependency yet); unknown *wire* fields (not in the pinned proto) aren't decoded.
- Follow-ups: Decoding unknown wire fields (`protoreflect` `GetUnknown()`) would catch WhatsApp changes before a whatsmeow bump.
