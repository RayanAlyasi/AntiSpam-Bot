## 2026-10-17 · F-009 · whatsmeow adapter implementing WAClient with error mapping

Part of the F-024 bundle (one PR; see F-024.md and `harness/deviations/F-024.md`).

- Built: `adapter.Client` implements every `wa.WAClient` method on whatsmeow through a small `api` interface (stubbed in tests): revoke via `SendMessage(BuildRevoke)`, edits via `BuildEdit`, reactions via `BuildReaction`, image sends via `Upload`, batched participant and join-request updates with per-participant errors. JIDs convert both ways without device parts (`FromWM`, `ToWM`). Errors map to `wa.ErrRateLimited`, `ErrTimeout`, `ErrNotAdmin`, `ErrNotFound` (whatsmeow error kept in the chain); `HandleEvent` turns `*events.TemporaryBan` into `*wa.TemporaryBanError` on every call until it lifts.
- Deferred: The connector itself (pairing, event registration, calling `HandleEvent`) is a later feature.
- Follow-ups: Error mapping is unit-tested against whatsmeow's error values, not a live server; the spike (F-000a) should confirm real server codes, especially per-participant result codes.
