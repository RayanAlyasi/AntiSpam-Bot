# F-106 · Anthropic adapter with prompt caching (WP-J bundle log)

## 2026-10-17 · PR 1: provider adapters and building blocks

Built (bundle contract `.agent/contracts/F-106.md`):
- `internal/ai/llm`: provider-neutral completion seam (`Completer`, `Request`, `Response`, `Usage`, `Caps`) and sentinel errors with HTTP/transport mapping.
- `internal/ai/anthropic` (F-106): official SDK, system prompt as a cacheable block, native JSON-schema output, no env credentials, no retries, errors → sentinels. Tests against an `httptest` fake of the Messages API.
- `internal/ai/openaicompat` (F-107): `/chat/completions`, strict `json_schema` or `json_object`, `auto` falls back to JSON mode once after a 400/422 and stays there; optional key for local servers.
- `internal/ai/budget` (F-109 core): atomic per-group/day and instance day/month reservations, 80% alert exactly once per window, prices → `ai_usage` usage; in-memory store.
- `internal/ai/cache` (F-110 core): sha256 key over text, context hash, model and prompt version; 30-day store lookup; single-flight cluster/campaign reuse; only definitive verdicts kept; in-memory store.
- `internal/ai/aimetrics` (F-109 metrics): Prometheus collectors from §16.
- `docs/AI.md`: providers, structured output, timeouts, budgets, cache, metrics.

Not done yet, so no feature is marked passing in this PR:

- Postgres stores for `ai_usage` and `ai_cache` (needs wp-c's goose/sqlc, F-004) and wiring of metrics and alerts (F-007, F-017).

## Follow-ups
- OpenAI-compatible adapter sends `max_tokens`; some hosted reasoning models want `max_completion_tokens`.
- wp-e's `DefaultMaxOutputTokens` (256) is low for Claude models that think by default; the wiring should not pass it to the Anthropic adapter unless the operator set it.
- Judge round 1 minors left for PR 2: per-group budget limits from group settings (pass the limit to Allow); alert if the Alerter fails at the 80% crossing; rapid property test for reservation atomicity; Record should reuse the reservation's day.
- OpenAI-compatible auto mode switches to JSON mode on any 400/422 (contract); a 400 for another cause (context length) also switches it. Narrowing to bodies that name response_format needs a contract change.
- Cluster reuse of not_spam for 24 h could let a spammer seed a cluster with a harmless variant; consider reusing not_spam only on exact key hits, or links/numbers in the cluster identity (plan change).

## 2026-10-17 · PR 2: classifier, verifier and early-AI safety

- `internal/ai/gateway`: `Classifier` implements `ai.AIClassifier` over an adapter (wp-e's `SelectMode`, `SystemPrompt`, `RenderData`, `Complete`); every adapter error ends as unsure. `New(ai.Config, …)` builds the configured adapter (nil when the AI is off). `Verifier` sends only the UNCERTAIN band to the AI through the result cache, cluster reuse and the group's budget, and resolves the band with `scoring.Resolve`.
- `internal/ai/safety` (F-112): `Decide` wraps `policy.Decide` with the early-AI safety rule; `AllowAISource` for commands and the website.
- `llm.PortableSchema`: adapters drop value constraints (minimum, maxLength, uniqueItems…) that native structured output rejects; answers are still validated strictly.
- PR 1 judge minors done: the shared cache call has its own deadline and stops when no caller waits any more; deterministic `synctest` flight tests; per-group budget limits (`Budget.AllowLimit`, `Item.GroupBudget`); a rapid property for reservation atomicity.
- Marked passing: F-106, F-107, F-111, F-112. Still open: F-108 (wp-a redaction F-101, wp-f inbox F-015), F-109 and F-110 Postgres stores (wp-c F-004).
