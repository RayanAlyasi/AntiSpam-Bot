# F-122 deviations

- §8.3 (b)/§9.5: in ask_before_action the timeout and fallback come from `enforcement.ask_before.*` (added by F-054); `leave` maps to the `dismiss` fallback. A `review.timeout` equal to the 6 h default is treated as unset in mode (b), so the 15-minute default applies.
- §9.5: `auto_ban` on timeout is re-checked when the timeout fires, against the item's and the group's current mode.
