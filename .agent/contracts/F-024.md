# F-024 Content Envelope types

**Goal:** `internal/envelope` declares the Content Envelope of DESIGN §5.3: one plain-Go structure per
message that analyzers read instead of raw protobufs. Types only; nothing here builds, unwraps or normalizes.

## Behaviour
- Exactly the §5.3 surfaces exist, with JIDs as `wa.JID` and message IDs as `wa.MessageID`.
- No whatsmeow or protobuf dependency, and no internal dependency other than `internal/wa`
  (standard library is fine). Only `internal/wa/adapter` may import whatsmeow.
- `Kind` is a string type whose values are stable snake_case names (they end up in goldens, metrics
  and evidence): `unknown text image video ptv sticker sticker_pack document audio voice contact
  location live_location event poll group_invite channel_invite product order payment interactive
  undecryptable`. Unrecognized types use `KindUnknown` (§6.13). View-once has no kind of its own (`IsViewOnce`).
- `TextSurface` keeps `Raw` exactly as received (zero-width, bidi, tag characters, Arabic, emoji all
  intact) next to `Norm`, which stays empty until the normalizer (§7.2, F-039) fills it.
  Text source constants: `SourceBody="body"`, `SourceCaption="caption"`, `SourceLinkTitle="link_title"`,
  `SourceVCardBizDesc="vcard_biz_desc"`, `SourcePollOption="poll_option"`. Builders may add more.
- `(Envelope).ForwardedManyTimes()` is true exactly when `ForwardingScore >= 5` (§5.3).
- `(QuotedRef).IsStatus()` is true exactly when `RemoteJID == "status@broadcast"` (a reply to a
  status). Broadcast lists (`<id>@broadcast`), groups and an empty RemoteJID are not statuses.
- A fully populated `Envelope` survives `encoding/json` Marshal/Unmarshal unchanged (deep-equal), so
  later golden tests can store envelopes. Every field is exported and JSON-encodable.

## Public surface (package `internal/envelope`)
- `Envelope{Bot, Group wa.JID; Sender Identity; MsgID wa.MessageID; Kind Kind; IsEdit, IsViewOnce,
  IsForwarded bool; ForwardingScore int; Texts []TextSurface; URLs []URLRef; Media []MediaRef;
  Contacts []ContactRef; Channels []ChannelRef; Invites []InviteRef; Mentions []wa.JID; Ads *AdRef;
  Quoted *QuotedRef; Status *StatusRef; Wrappers []string}` and method `ForwardedManyTimes() bool`.
- `Identity{LID, PN wa.JID; PushName, VerifiedName string}`
- `Kind` (string) and the `Kind*` constants above, e.g. `KindStickerPack`, `KindLiveLocation`, `KindGroupInvite`.
- `TextSurface{Source, Raw, Norm string}`, `URLRef{URL, Source string}` (Source e.g. text, preview, vcard, location, event).
- `MediaRef{Type Kind; SHA256 []byte; Mimetype string; Size int64; Thumb []byte; Downloadable bool}`
- `ContactRef{DisplayName, FullName, Org string; Phones, WAIDs []string; BizName, BizDescription string; URLs []string; IsSelfContact bool}`
- `ChannelRef{JID wa.JID; Name, InviteCode, Source string}`, `InviteRef{Code string; Group wa.JID; GroupName, Source string}`
- `AdRef{Title, Body, SourceURL string}`, `QuotedRef{ID wa.MessageID; Sender, RemoteJID wa.JID; Kind Kind}` with `IsStatus() bool`
- `StatusRef{ForwardedFromStatus bool; SourceType, AttributionType string; Attributions []StatusAttribution; IsGroupStatus, IsStatusMention bool}`
- `StatusAttribution{Type, ActionURL string; ExternalShareURLs []string; ChannelJID, AuthorJID wa.JID}`

## Out of scope
Building envelopes from whatsmeow messages (adapter features), unwrapping (§5.2, F-025), normalization
(§7.2, F-034/F-039), URL extraction (F-046), vCard parsing (F-028), fingerprints, analyzers, extra
per-kind fields (dimensions, durations, file names, extracted phone numbers: later features add them),
round-tripping invalid UTF-8 through JSON.

## DESIGN.md refs
§5.3 (primary); §5.2, §6.6–6.9, §6.13, §6.15, §6.18, §7.2, §7.7 for field meaning.

## Assumptions
- Sender's type is `envelope.Identity`, a value snapshot, not `internal/identity` (keeps envelope a leaf).
- `MsgID`/`QuotedRef.ID` use `wa.MessageID` (a string type) rather than bare `string`.
- Protobuf enums (status source/attribution types) are carried as their enum-name strings.
- `IsStatus` and `ForwardedManyTimes` are derived methods, so they can't disagree with their source fields.
- Fields beyond §5.3 may be added later; tests use keyed literals so additions don't break them.

## Acceptance tests (`acceptance/envelope`)
- `TestKindNamesAreStable`: every Kind constant has its snake_case name and all are distinct.
- `TestTextSourceNamesAreStable`: the five §5.3 text source constants have their documented names.
- `TestForwardedManyTimes`: scores 0, 1, 4 are not "many times"; 5 and 127 are.
- `TestQuotedRefIsStatus`: only `status@broadcast` is a status; broadcast list, group, person, empty are not.
- `TestEnvelopeJSONRoundTrip`: a fully populated envelope (obfuscated Unicode Raw, every ref) round-trips unchanged.
- `TestZeroEnvelopeHasNoSurfaces`: the zero Envelope has nil slices and pointers and is not forwarded many times.
- `TestEnvelopeHasNoWhatsmeowDependency`: `go list -deps` shows no whatsmeow, protobuf or internal package except internal/wa.
