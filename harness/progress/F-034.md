## 2026-10-17 · F-034 (work package A: F-034, F-035, F-036, F-037, F-038, F-046, F-047, F-101)

User decision (fast track, relayed by the coordinating session): these eight features ship as one
PR, the F-034 contract was approved, F-035 onwards are contract-only (no hidden tests), and one
judge review covers the bundle.

- Built:
  - `internal/normalize`: `Text(raw) Result` with `Raw`, `Norm`, `Stripped`, `Skeleton`, `Leet`,
    `Loose`, `EmojiTokens`. Each step is its own exported function: `Fold` (NFKC loop),
    `StripInvisibles`, `StripFloods`, `FoldArabic`, `LooseArabic`, `CollapseSeparators`,
    `SqueezeRepeats`, `Leet`, `Skeleton`, `EmojiTokens`, plus `IsInvisible`.
  - TR39 `confusables.txt` 16.0.0 embedded unchanged in `internal/normalize/data/` (licence note
    in its README). 17.0.0 wasn't published at the pinned URL.
  - `FindPhones(text, region) []Phone`, `ParsePhone(s, region)`, `ErrInvalidPhone`, using
    `github.com/nyaruka/phonenumbers` v1.8.1.
  - `internal/normalize/urls`: `Extract` (defanged, spaced, fullwidth, IDN, bare domains with an
    ICANN suffix) and `Canonicalize` (`URL`, `Target`, `TargetKind`), with
    `golang.org/x/net/{idna,publicsuffix}`.
  - `internal/normalize/redact`: `Text(s, Options)` and `PhoneHash`.
  - `go.mod`: phonenumbers added; `golang.org/x/text` and `golang.org/x/net` move from indirect to
    direct.
- Deferred: F-039 (fill `Envelope.Texts[].Norm`, attach phones) waits for the envelope package.
- Follow-ups:
  - Arch map (human change): with `harness/proposed/.go-arch-lint.yml` as it is, go-arch-lint
    flags `internal/normalize/urls` and `internal/normalize/redact` importing
    `internal/normalize` (3 notices; the map isn't active yet, so the gate passes). Checked fix:
    `normalize: { in: internal/normalize }`, a new
    `normalize-ext: { in: [internal/normalize/urls/**, internal/normalize/redact/**] }` with
    `mayDependOn: [normalize]`, and `normalize-ext` added wherever `normalize` is allowed
    (envelope, detect, ai, wa-adapter). `review` and `store` also need `normalize-ext` for redaction.
  - Tag-flag exemption (per contract) accepts any length of tags between U+1F3F4 and U+E007F, so a
    "flag" can carry hidden tag text without raising `Stripped`. Consider capping it at the
    longest real subdivision flag.
  - ZWJ/ZWNJ in Indic scripts (conjunct control) are counted; only Arabic-script and emoji uses
    are exempt.
  - Squeeze applies to every letter run, so `www.` becomes `ww.` in `Norm`. URL extraction reads
    the raw text, so links aren't affected.
  - `FindPhones` has 4096 parses per call for each kind of start (plain, word or run start,
    international). Conspicuous noise of the same kind (about 10 KB of number words, or a flood
    of spaced digits before an unmarked national number) can still use one up. `redact` masks
    any spelled-out run of 9+ digits regardless, so nothing leaks there. Idea: skip prefixes
    whose length doesn't fit the region before parsing.
  - Judge round 1 nits left: `ftp://example.com` extracts `http://example.com` from the bare
    domain; a later matcher could use a mark-stripped variant against light (1–3 mark) Zalgo.
  - Arabic number words with the conjunction prefix (`وخمسة`) aren't read.
