## 2026-10-17 · F-021 · learn phone numbers from free sources (WP-F, PR 1)

- Built: `Service.Learn(lid, pn, src)` records a pair with its source on each identity row and the country code (nyaruka/phonenumbers) on PN rows; `NumberPrefix` derives the prefix for the §7.6 statistics. Sources wired: `Tracker` learns from participant lists (`JoinedGroup`, `GetGroupInfo` refreshes, `GroupParticipant.PhoneNumber`, whatsmeow LID-store pairs attached to `GroupInfo` events) and from `GroupInfo.SenderPN`/`JoinedGroup.SenderPN` (source `event`). The connector's `LIDResolver` reads whatsmeow's LID store and asks usync only in the PN → LID direction, rate-capped.
- `Learn` never calls `LIDForPN`; LID-only persons never trigger a remote lookup.
- Deferred: SenderAlt and DM learning are called from the inbox worker (follow-up PR, with F-015/F-016 wiring); self-vCard confirmation belongs to a later feature.
