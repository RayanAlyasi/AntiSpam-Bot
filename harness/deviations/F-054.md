# F-054 deviations (group settings document)

- §8.3 (b) / §12.1: the ask_before_action fallback ("default 15 minutes → delete, no ban; or leave") has no key in the §12.1 example, and `review.timeout`/`review.on_timeout` (6h, keep_deleted_no_ban) can't express it. Added `enforcement.ask_before.timeout` (15m) and `enforcement.ask_before.on_timeout` (`delete_no_ban` | `leave`). Validation refuses any other fallback, so it can never ban.
- §8.6 / §12.1: "max deletions per minute" has no key or default in §12.1. Added `limits.max_deletions_per_minute`, default 30 (above the 10 writes/min per-group bucket of §10.3, so normal deletion bursts never trip it, low enough to stop a bad rule within a minute).
- §12.1: `review.language` default is `en` (the §12.1 example shows `ar` as an example value).
- §12.1: setting a matrix cell to a non-auto_ban action by its `.action` key drops the cell's `require_source`/`else` instead of rejecting the document, so `.set enforcement.autoban_matrix.videos.action ask` works.
- Validation is the Go struct (strict decode, `Validate`) plus a generated JSON Schema checked by a small built-in validator (types, enums, required and unknown keys), not a third-party JSON Schema library.
