## 2026-10-17 · F-024 bundle (F-009, F-024–F-032) · §5.2, §5.3, §6.13, §10.5

- **Builder, unwrapper and vCard parser are files of `internal/wa/adapter`, not sub-packages.** go-arch-lint (proposed config) rejects imports between sub-packages of the `wa-adapter` component, so `adapter/build` and `adapter/vcard` were flattened into `adapter` (`Build`, `Unwrap`, `ParseVCard`).
- **Unwrap starts from the raw message (§5.2 says "after UnwrapRaw").** `Build` unwraps `evt.RawMessage` when present, so ephemeral, view-once and edit wrappers are recorded in `Wrappers` like the FutureProof ones. Because those count toward the depth cap, the cap is 8 instead of "e.g. 5", plus a total of 32 visited messages. Hitting a cap appends `envelope.WrapperTruncated` to `Wrappers`, so nesting deeper than real clients do is visible to policy rather than silently hiding content.
- **Every layer of the wrapper tree is analyzed.** A crafted message can carry content beside a wrapper; the unwrapper returns every content-bearing layer instead of following one chain.
- **Unknown-type metric (§6.13) is `BuildResult.Unknown`, not a Prometheus counter.** Prometheus isn't a dependency yet; the caller that wires metrics counts these field names.
- **Temporary bans (§10.5).** whatsmeow reports a temp ban only as an `*events.TemporaryBan` event, not as a call error. `Client.HandleEvent` records it, and every call returns a `*wa.TemporaryBanError` (with the time left) until it lifts.
- **Error mapping choices (§10.5).** "Not in group" maps to `wa.ErrNotAdmin` (the bot can't act there); a disconnect (`ErrNotConnected`, `ErrIQDisconnected`) maps to `wa.ErrTimeout` (transient, retried); a hidden or missing profile picture maps to `wa.ErrNotFound`.
- **Quoted messages.** Only a quoted *status* has its content merged into the envelope (sources prefixed `quoted_status_`, §6.18); a normal quote records only `QuotedRef` with the quoted kind, so a reply isn't judged by the message it answers.
- **`MediaRef` gained `Width`, `Height`, `Seconds`, `PageCount` and `Flags`** (F-027 asks for page count and sticker flags; §6.2–6.6 list dimensions and durations). `wa.Revoke` was added for sender/admin revokes (F-031).
- **Revokes need the edit attribute (§2.1).** A message is a revoke only when `Info.Edit` is "7" (sender) or "8" (admin), and `ByAdmin` comes from "8" alone. The sending client sets that attribute and the key travels encrypted, so neither is server-checked: a "7" revoke must name the sender's own message (LID or phone number) or it's ignored, and a revoke without a REVOKE ProtocolMessage and ID is ignored. A REVOKE ProtocolMessage without the attribute is ignored too, and any content beside it is still analyzed. Whether the server checks "8" for admin status is for the spike.
- **Bounds.** At most 32 contact cards per message are parsed (the display names of the rest are still kept as text, and the envelope is marked with `WrapperTruncated`) (each vCard is capped at 64 KiB and 256 properties, and unfolding is linear). A message's kind prefers any non-text kind over text, so adding text to a video doesn't dodge a "no videos" policy.
- **Transient server errors.** IQ errors match by code when the text differs, and 500/503 (IQ or send) map to `wa.ErrTimeout`, whose doc now says "or failed transiently".
