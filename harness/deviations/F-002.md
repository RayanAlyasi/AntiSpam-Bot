# F-002 bundle deviations (F-001–F-008, F-099)

- **§19.1, §23.7 (new env var `HTTP_ADDR`):** DESIGN names no listen address. Added `HTTP_ADDR`
  (default `:8080`) in the same env-var style as `DATABASE_URL`. It is new operator API.
- **§14 (River's schema):** DESIGN puts app tables in `app` and whatsmeow's tables in `whatsmeow`,
  but doesn't say where River goes. River's tables go in `app`, so there's no third schema to back
  up or grant. goose's own version table stays in `public`, goose's default, because it is needed
  before `app` exists.
- **F-000 `TestRun` / `-check-config`:** the committed F-000 test calls `run(getenv, out)` and
  expects exit 0 with no environment. A server can't do that once it needs `DATABASE_URL`, so `run`
  became the `-check-config` mode (validate and exit). The server path is `serve`, which exits 1
  without `DATABASE_URL`. A test-change-request can retarget that test if the human prefers.
- **§4.1 (shutdown bound):** the default `-shutdown-timeout` is 8s, under Docker's 10s stop grace.
- **§16 (`/readyz`):** the connector isn't implemented yet, so readiness reports 0 bots and is 503.
  Health checks should use `/healthz`, as `docs/RUNNING.md` says.
