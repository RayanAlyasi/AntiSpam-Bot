## 2026-10-17 · F-016 · §5.1, §13.6

- **"Configured group" means a groups row with status `active`** (the bot is an admin there). Tracked groups where the bot isn't admin yet are not moderated, but messages there are still parsed for commands (which check permissions); untracked groups are ignored.
- **The routing admin check uses the event-maintained cache** without the 10-minute forced refresh. That refresh is for permission checks on writes (§13.3); applying it here would cost one group-info IQ per group every 10 minutes.
- **Broadcast-list messages go to the DM handler**, since they appear in the sender's DM thread and only affect reputation (§2.1, §5.1).
