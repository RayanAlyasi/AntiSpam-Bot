# F-035: TR39 confusables skeleton

> Acceptance tests were waived by the user's fast-track decision for v0.1 work package A (this feature isn't core). The builder's table, property and fuzz tests carry the proof, and the judge checks them against this contract.

**Goal:** `normalize.Text` also returns a confusables skeleton of `Norm`, so look-alike letters from other scripts match their Latin form: `frее` with Cyrillic `е` matches `free`.

**Behaviour**
- `Skeleton` is the Unicode TR39 skeleton of `Norm`, from an embedded, pinned copy of `confusables.txt` (version and Unicode licence noted next to it). Nothing is fetched at runtime.
- Cyrillic, Greek, Armenian and other look-alikes fold to the Latin prototype: `frее` (Cyrillic е), `ρауpаl` (Greek ρ, Cyrillic а/у) and `fr𝖾e` give the same `Skeleton` as `free`/`paypal`. Comparisons are case-insensitive (`strings.EqualFold`), because the TR39 prototypes mix case (`0`→`O`, `1`→`l`).
- Patterns are prepared the same way: `Text(pattern).Skeleton` is what a matcher compares against, so a pattern matches its own confusable variants. Skeleton can differ from `Norm` even for plain ASCII (TR39 maps `m`→`rn`). That's expected.
- `Raw`, `Norm` and `Stripped` keep their F-034 meanings, and their values don't change. Legitimate single-script text (Russian, Greek, Arabic) keeps its `Norm` and gets `Stripped == 0`. Only `Skeleton` is folded.
- Deterministic, never panics, valid UTF-8, and the whole `Text` call stays linear (F-034's 256Ki-rune bound still holds).

**Public surface:** package `internal/normalize`: new field `Result.Skeleton string`, filled by `Text`. No new functions.

**Out of scope:** mixed-script detection as a signal, host look-alike detection against brands (URL analyzer step 7, a later feature, reads `Skeleton`), case folding in matchers, leetspeak (F-036).

**DESIGN.md refs:** §7.2 step 3, §6 URL analyzer step 7.

**Assumptions**
- The skeleton goes in its own field, not in `Norm`. Folding `Norm` would turn legitimate Cyrillic/Greek text and digits (`0`→`O`) into Latin and break keyword lists written in those scripts, which would be a false-positive risk.

**Proof (builder tests):** a table of confusable/plain pairs with equal `Skeleton` (Cyrillic, Greek, math-alphanumeric, mixed); single-script text with `Norm` unchanged and `Stripped` 0; a pattern matching its own skeleton; a fuzz target extending F-034's (no panic, valid UTF-8, F-034 properties of `Norm` intact).
