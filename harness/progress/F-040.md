# F-040 bundle: analyzer framework, scoring, bands, AI core, locales

Date: 2026-10-17. One work package for F-040, F-050, F-051, F-103, F-104, F-105 and F-078
(contract: `.agent/contracts/F-040.md`; hidden tests for F-050 and F-051 only).

## Built
- `internal/scoring` (F-050, F-051): `Signal`, versioned `Weights` (YAML, embedded default
  `weights.yaml`), `Score` (sigmoid of bias + Σ, one count per code, hard signals excluded,
  overflow-safe), `Result.Explain`, `Thresholds`, `Band`, `Source`, `Classify`, `Resolve`,
  `Verdict.DeletesAsSpam`. Property tests with rapid for the §18 invariants.
- `internal/detect` (F-040): `Tier`, generic `Analyzer[E, P]`, `State`, `Registry[E, P]` with enable
  flags, `Runner[E, P]` with per-tier budgets, concurrent analyzers merged in registration order,
  CERTAIN/clean short-circuits, `Fast()`/`Slow()` lanes, failures (error, panic, budget) reported
  and dropped.
- `internal/ai` (F-103, F-104, F-105): `AIClassifier`, `ClassifyRequest` with the context-bundle
  shape, `Caps`, `Config` (yaml tags, `WithDefaults`, `Validate`, `APIKey`), `ParseVerdict`,
  `VerdictSchema`, `SelectMode`, `Complete` (retry once, then unsure), `SystemPrompt`,
  `PromptVersion`, `RenderData`; `internal/ai/fake`.
- `locales` (F-078): `en.yaml`, `ar.yaml`, `Load`/`Parse`/`Render`/`Command`/`Keyword`.
