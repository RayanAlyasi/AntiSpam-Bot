# F-034 bundle: deviations and judgement calls

Where DESIGN.md §6/§7.2 and the contracts left room, these are the choices made (the more
conservative option each time):

- **Flood detection (F-034).** A flood is decided per base on the invisible-stripped input and
  measured as NFKC leaves the cluster (a mark that composes into the base doesn't count; U+0344
  counts as two), so precomposed and decomposed spellings are judged alike. The base is kept.
  `Stripped` counts input mark characters; a final clamp keeps it at most the input rune count.
  Floods exposed later (compatibility characters that NFKC turns into marks, or marks joined when
  F-037 removes tatweel) are stripped and counted too, so `Norm` stays idempotent.
- **Extra invisibles (F-034).** Besides the §7.2 list, U+034F, U+061C, U+115F, U+1160, U+17B4,
  U+17B5, U+180E, U+3164, U+FFA0 and U+1BCA0–U+1BCA3 are removed and counted (the contract allows
  other default-ignorables). Mongolian free variation selectors are kept.
- **Collapse tie rule (F-036).** A run of spelled-out letters is "tied" to a neighbouring word only
  through a gap that contains a non-space separator (`a.b.c.com`, `J. R. R. Tolkien`), so
  `f r e e money` still collapses. Newlines are not collapse gaps.
- **Leet collapse (F-036).** `f.r.3.3` collapses in `Leet` only when the spelled-out run has at
  least one leet character and as many letters as leet characters.
- **Phone candidates (F-038).** Digit groups join across up to 3 visible separators
  (space, `-`, `.`, `(`, `)`, `/`, dashes); from each start the longest valid prefix of whole
  groups wins. Three groups shaped like a date with date separators are skipped. `wa.me/` and
  `phone=` mark the digits after them as international.
- **Canonical URLs (F-047).** Userinfo (`user@`) is dropped from `Canonical`; the host is what
  lists match on.
- **Spaced dots (F-046).** Without a scheme or `www`, a spaced dot joins only with a space before
  it and when the dotted name ends in a common suffix written in lower case (any case if a path
  follows). Suffixes that are also English words (me, shop, live, …) also need no word right
  after them, and `evil. com` (a space only after the dot) isn't joined. A bare domain whose
  suffix is such a word written Title-case and followed by a word (`work.Me too`) isn't a link;
  `Evil.Com` and `work.Me` alone are.
- **Phone parse budget (F-038).** 4096 parses each for plain digit starts, for number-word and
  run starts, and for internationally written starts (`+`, `00`, wa.me link), so noise of one
  kind can't hide a number of another.
- **Redaction (F-101).** A `[phone:<id>]` whose id is all digits and reads as a phone number is
  masked as `[phone]` instead of trusted. Overlapping masks are joined so no part of a masked item shows; the
  earliest span gives the placeholder.
